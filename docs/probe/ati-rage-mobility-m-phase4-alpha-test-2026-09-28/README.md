# ATI Rage Mobility-M Phase 4 alpha-test evidence

Physical target: Gateway Solo 2150, ATI Rage Mobility-M `1002:4C4D`
revision `64`, 4 MiB SGRAM, 1024x768x16 desktop.

Build `ati-phase4-alpha-table-20260928-a` exercised all eight
`ALPHA_TST_CNTL` comparison encodings independently. Every scene used the
already-proven 8x8 ARGB1555 texture with alpha 0 red texels in its left half,
alpha 255 green texels in its right half, and reference alpha 127. Thus the
two populations are strictly below and above the reference; no texel equals
it. Three separated probes checked the expected pass mask rather than only a
pixel count.

All eight scenes passed twice, byte-identically, on boot 11. Every report has
`Status=0x0001FFFF`, zero interior, exterior, texture/guard and restoration
mismatches, and no timeout or recovery reset. The observed masks and accepted
artifact identities are:
