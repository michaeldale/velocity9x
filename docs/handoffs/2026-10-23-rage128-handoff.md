## What to know before touching the CCE

- **Stop it when done.** Stop the microengine (`PM4_MICRO_CNTL` 0) and
  reset the engine after submitting. A probe that left it free-running
  hung A8U4I5 idle a minute later (boot 522), which needed a power cycle.
  The cause is not established.
- **Write in pairs.** PIO packets go to `PM4_FIFO_DATA_EVEN` and `_ODD`
  alternately, padded to a pair with a type-2 dword. Everything written to
  EVEN executes nothing.
- **Open the 3D scissor first.** Primitives clip to the 3D context
  scissor `SC_TOP_LEFT_C` / `SC_BOTTOM_RIGHT_C`, which POST leaves at
  zero. Write the context block before any primitive.
- **Write the PLL index a byte at a time.** `CLOCK_CNTL_INDEX` bits 9:8
  select the live pixel-clock divider (`0300` on this card), so write the
  index as a byte.
- **Microcode licence.** The microcode is linux-firmware's
  `r128_cce.bin`: MIT, AMD, SHA-256 `13a9e203...`. Michael accepted
  shipping it with the notice (2026-10-22). It is not yet in the
  repository; the probe reads it from `C:\V9XDIAG`.

## Next, in order

1. **Phase 3 remainder.**
   - GDI acceleration: the ati family's GDI path has no Rage 128 arm.
   - The 32 MiB mapping: the family maps 16 MiB.
   - Engine reset in `eng_r128.c`.
   - Measure DirectDraw at 8 and 32 bpp through the HAL. V9XDDP always
     tests at 16 bpp.
2. **Flips** via `CRTC_OFFSET` and a vertical-blank source. Michael watches
   the monitor.
3. **Direct3D on the CCE.**
   - Add the microcode to the HAL, with its notice.
   - A submission core: PIO pairs, a PM4_STAT space wait, and a stop and
     reset around every hand-back to direct 2D writes.
   - Context emit.
   - Then textures (`PRIM_TEX_CNTL_C`, `TEX_SIZE_PITCH_C`, offsets) and
     Z (`Z_OFFSET_C`, `Z_PITCH_C`, `Z_STEN_CNTL_C`).
   - Then V9XD32, V9XDDP, 3DMark 2000, and HL D3D against the reference.
4. **Decide on a ring.** Decide whether PIO is fast enough, or a
   bus-master ring is needed, by measuring against the reference
   figures.
