# GeForce 9500 GT (G96): 1440x900 is listed again with no EDID, and the driver sets it

Date: 2026-11-28

Follows [2026-11-28-g96-no-1440x900-without-edid.md](2026-11-28-g96-no-1440x900-without-edid.md),
whose reading this evidence disputes. M-Z2T02D (GitHub issue 30), boot 20,
the nvidia set of [2026-11-28-g96-clocks-measured.md](2026-11-28-g96-clocks-measured.md)
(7ca586c8-dirty tree). Evidence:
[g96-1440x900-boot20-m-z2t02d-2026-11-28/](../probe/g96-1440x900-boot20-m-z2t02d-2026-11-28/).

## What the BIOS lists now

| | Issue 30's `vbe` log | Boot 13 | Boots 18 and 20 |
|---|---|---|---|
| Modes listed | 29 | 30 | 29 (`VbeCache l=29`) |
| Wide | 1280x800, 1280x720, 1440x900 | none | 1280x800 (8, 32), 1280x720 (32), 1440x900 (8, 32) |
| Large 4:3 | none | 1280x1024, 1600x1200 | none |
| `Edid` in `V9XMODES.INI` | not logged | none | none |

Boot 18's list was read in the audit the same day; boot 20's
`V9XMODES.INI` and `V9XBOOT.INI` are in the evidence (modes 0164h and
0165h are 1440x900 at 8 and 32 bpp). The owner had said, before boot
18, that the monitor was taken off the machine; whether it was unplugged
or switched off is not known.

## What this disputes

The earlier record read boot 13's missing wide modes as the BIOS
finding no display at power-on, since `Edid=none`. Boots 18 and 20
also read `Edid=none` and list the wide modes, so no EDID through the
driver does not mean no wide modes. The list changes between boots of
the same card and VBIOS (`rev=6294`); what decides it is not measured.
The driver's EDID read sees nothing on any boot so far, so it cannot
say what the BIOS saw.

## The driver sets it

`V9XMSW /set:1440x900x32`: `Result=PASS`, `ChangeResult=0`; the agent's
`display` read 1440x900x32 and its screenshot showed the desktop at
1440x900 (`desktop-1440x900.png`, half scale). `/set:1024x768x32` put
the owner's desktop back. So when the BIOS lists 1440x900, the `nvidia`
package offers and sets it; when it does not, it cannot. Nothing was
seen on a monitor.

## Not done

What makes the VBIOS build one list or the other (a monitor on DVI or
VGA at power-on, DDC on the card's connector) needs the owner: a boot
with the monitor on the 9500 GT, then `V9XMODES.INI`.
