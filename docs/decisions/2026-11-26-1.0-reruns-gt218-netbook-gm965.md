  `FlipVSyncOverridden` 0 to 0.

## Netbook GMA 950: GLQuake -nomtex +gl_texsort 0

W9QI2BE2 (945GSE), boot 371, released 0.60.0. GLQuake 0.97 windowed
640x480, `-nomtex +gl_texsort 0 +timedemo demo1`, as the 2026-10-08
Rage XL run.

- 969 frames, 43.9 fps. The ICD's `paths` line: `hw-refused=0/0` of
  1,256,219 batches, no `refused tex` line for the process. The Rage XL
  refused 111,915 lightmap batches in October; the REPLACE-as-MODULATE
  rewrite (61b58b8a) has removed the refusal here.
- **The picture is wrong:** the agent screenshot shows the world as grey
  lighting only, no wall or floor texture. The control, the same demo
  with multitexture (no `-nomtex`), shows textured, lit walls at the
  same place (69.9 fps).
- The counters line reports `alpha-dropped=23572`. Reading, not
  measured: GLQuake's RGBA lightmaps lose their alpha as RGB565
  textures, so the blended lightmap pass covers the base texture instead
  of darkening it. Before the rewrite those batches were refused and the
  walls drew unlit.

Evidence: `../probe/netbook-glquake-nomtex-2026-11-26/` (the run's ICD log lines in `V9XGL-run.LOG`, `mid.png`;
`control-mtex/` the multitexture run and its four screenshots).
