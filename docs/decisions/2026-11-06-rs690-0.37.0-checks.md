## Glide and 3DCIF draw nothing on this chip

Glide 2's open, clears and flips pass. Every triangle, line and
textured draw reads back the clear colour. Glide and 3DCIF draw through
the HAL's render interface. The RS690 map refuses every render-interface
draw (`V9X_D3D_RS690_REFUSE_EXPLICIT`). `v9x_r3d_fallback` gives a
software fallback only to engines that passed the mixed-engine probe:
Gen3, MGA and Rage 128. The RS690 has no fallback, so a refused draw is
dropped. Under vbe the software engine drew both, so on this chip the
ati package draws less than vbe for Glide and 3DCIF. OpenGL is
unaffected. Michael: acceptable for 0.37.0. The likely fix is
`V9XDDP /mixed` on this chip, then the RS690 in `v9x_r3d_fallback`.

## 3DMark 2000: some far terrain drawn salmon-red

hard edges. The Rage 128's 0.36.0 grabs fade the same hills to grey.
Filed as `docs/issues/2026-11-06-rs690-3dmark2000-pink-terrain.md`.
