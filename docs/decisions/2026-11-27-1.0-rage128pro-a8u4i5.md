# Rage 128 Pro on the 0.61.0 tree: probes pass but V9XD32's X8R8G8B8 texture, and 3DMark 2000 runs to its score at its defaults

Date: 2026-11-27. Machine: A8U4I5 (Pentium III 1 GHz, 128 MiB, Windows
98 SE), its Rage 128 Pro (Rage Fury Pro/Xpert 2000 Pro, `1002:5046`,
subsystem `1002:0018`). Build: the `ati` package of `620b48c3-dirty`
(the 0.61.0 tree), installed by `run-release-checks.ps1 -Machine
rage128pro` (WININIT renames, `reset`, 8 of 8 files hash-checked, boot
727 to 728). The sixth card of the A8U4I5 round; the last Velocity9x
runs on this card were in early November.

## Getting the card onto our driver

The devnode's `Driver` is `Display\0007`, the Velocity9x Rage XL key:
there is no Velocity9x key of the Rage 128's own on this machine, and
the `ati` package's one set of files serves both. Windows came up in
16-colour VGA with "There is a problem with your display settings"
because `SYSTEM` held the SiS 6326's `sis` files; it then installed the
monitor from `MONITOR.INF`. The runner's install of the `ati` set fixed
the rest. Because the key is the Rage XL's, 3DMark and Display
Properties name the card "ATI Rage XL PCI"; cosmetic, left as it is.
