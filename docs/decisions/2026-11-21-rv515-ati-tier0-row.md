# RV515 tier-0 row in the ati family runs on M-5CAPM3

Date: 2026-11-21
Machine: remote-help `M-5CAPM3`, Radeon X1300 `1002:7146` (subsystem
`1002:0322`), boot 36.
Build: ati package `e25a096f` (branch `ati-rv515`), installed by Have Disk
from `C:\V9XATI` over the 0.57.0 `vbe` install (the vbe package stays in
`C:\V9XPKG` for rollback). Reports in
[`docs/probe/m-5capm3-rv515-2026-11-21/ati-tier0-boot36/`](../probe/m-5capm3-rv515-2026-11-21/ati-tier0-boot36/).
Plan: [`ati-rv515-x1300.md`](../plans/ati-rv515-x1300.md), phase 1.

## What was installed

The Have Disk list offered "Velocity9x ATI Radeon X1300 (RV515)" as a
compatible device, matched on `PCI\VEN_1002&DEV_7146` (the manual
any-VBE entry the owner used before matches nothing). Right after the
wizard, `V9XMINI.VXD` and `V9XHAL.DLL` in `SYSTEM` matched the package
but `V9XDISP.DRV` still had the vbe build's hash: it was loaded, and
Windows replaced it at the next start. After the reboot it matched.
Checking the DRV only before rebooting would have reported a failed
install.

## Boot 36

- `V9XHW.INI`: `Adapter=ATI Radeon X1300 (RV515)`, `VendorId=1002`,
  `DeviceId=7146`, `Acceleration=none`, `Direct3D=not-advertised`,
  `EngineCaps=00000000`, `ScreenShadow=on`, `ColourLayout=565-auto`.
- `V9XBOOT.INI`: `Stage=enable-ok`, 640x480x16, pitch 1280,
  `MtrrWrite=ok s=2 b=d0000001 m=ff000800` (16 MiB write-combined at the
  frame buffer, as under vbe).
- `V9XGDI /auto` PASS, `V9XMSW /cycle:4` PASS 4/4, `V9XMSW /depth:4`
  PASS 4/4, all reporting `Build=e25a096f`. No restart during the runs.

## One difference from the vbe package

`Direct3DMode=none` and `Direct3DDefault=0`, where the vbe package gave
`software` and 2. That is the families' defaults, not this row: the vbe
manifest defaults Direct3D to the software rasterizer because tier-0 has
no other engine (`packaging\families\vbe\family.psd1`, the
Direct3DDefault comment), and the ati family defaults to hardware, which
`v9x_d3d_mode_resolve` turns into NONE on a chip with no 3D. The owner
can choose Software on the settings page. Not changed here: it is a
family-wide default, and the RV515 is meant to get its own engine.
