## Read by hand

- **GeForce 210, V9XD32 FAIL (`Failures=0x00000002`).** The new chip's
  first release check, so nothing to compare. `T22XOk=0`: an X8R8G8B8
  texture draws nothing, the gap the GT218 record and the changelog
  already list, as are T20 and T21 being partial. Every other test that
  ran reads as in the GT218 record's last run (T2, T3, T5-T10, T14, T15,
  T22A pass; T19 skips, no pixel shaders).
- **GeForce 210, V9XGLIDP 5 failures.** Texture565, TexturePalette,
  TexturePaletteChange, ChromaKeyed and ChromaOff all read 0000 where a
  colour was expected: Glide's textured draws put nothing on screen. The
  untextured checks pass. Glide was never run on the GT218 before; it
  is listed as not working in the README, not investigated.
- **Netbook, OpenGL swap 6.45 ms** against 0.51.0's 0.79. One rerun of
  V9XWPRS on the same boot (353), same build, read 0.78 ms
  (`gma950/wprs-rerun-V9XWPRS.INI`): the first-run reading seen before on
  this machine, not a change in the release.
- **M-NZHWBR now holds the HD 2400 Pro (RV610),** under the entry that
  checked its HD 2600 XT in 0.51.0, so its "no verdict changed" compares
  two different chips. Every probe passes on the RV610.
- **M-BXMFA8** was the list's `hd7470` entry; it is now `gt218`, the
  `nvidia` package.
