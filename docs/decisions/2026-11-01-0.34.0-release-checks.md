## The blocker: HD 4600 flicker and blocky sky

[Issue record](../issues/2026-11-01-haswell-3dmark2000-flicker-and-blocky-sky.md).
The released 0.33.0 package shows both, so neither came with 0.34.0.

- **Flicker.** At DDI 7 the render target is named by CreateSurfaceEx
  handle each frame; a flip moves the handles round the chain with the
  memory, and the driver followed the wrong object, drawing into the page
  on screen (21,358 draws in one Game 1 run, then 0).
- **Sky.** At DDI 6 and 7 every engine published only the DX5 filter
  words, so DX6/7 programs saw no linear filter and point-sampled
  everything. The DX6 bits are now derived as DDI 8 derives them.

Michael watched 3DMark 2000 on the 4570's monitor after the fix: "looks
good".

The filter change reaches every engine. Here it ran on the HD 4600, the
GMA 950 and both Evergreens. On the HD 5770 3DMark 2000 now asks for
LINEAR and MIPLINEAR as on the HD 4600 (`FilterMagSeen` 0x6,
`FilterMinSeen` 0x16), completed with 0 refusals and 0 draws into the
presented page, and its ten grabbed Game 1 frames show the trees. The
owner's flicker report on that card (single and double buffering) was
not re-run; this was triple buffered.
