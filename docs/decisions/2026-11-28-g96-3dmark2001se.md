# GeForce 9500 GT (G96): 3DMark 2001 SE runs to its score, 1397

Date: 2026-11-28

On M-Z2T02D (GitHub issue 30), boot 13, the driver set of
[2026-11-28-g96-direct3d.md](2026-11-28-g96-direct3d.md) (snapshot
`DriverBuild=HalBuild=1.1.0 3ba059d5-dirty`, the tree committed as
3a1335ec). Evidence:
[g96-3dmark2001se-m-z2t02d-2026-11-28/](../probe/g96-3dmark2001se-m-z2t02d-2026-11-28/).

## Install

3DMark 2001 SE was not on the machine. The free edition's installer and
its build 330 patch (`Y:\General\Computer\Installers\3dmark2001se.exe`,
SHA-256 `7dbfedb7...04b0`; `3DMark2001SE_patch.exe`, `51bd847f...a6c5`)
were uploaded over the relay to `C:\V9XINST` and installed with the
defaults; Michael accepted the free licence in chat. No registration
key. DirectX on the machine is 8.1 (`4.08.01.0901`).

## The run

Desktop 1024x768x32. 3DMark's own defaults: 1024x768, 32-bit colour,
compressed textures, double buffered, D3D software T&L, low game detail;
all seven game tests, six theoretical and four DX8 feature tests (the
free edition's set). Driven by agent: Benchmark clicked, windows polled.
It ran to "3DMark2001 SE Overall Score" in about 7.5 minutes.

**Score 1397**, recorded, not compared. 3DMark says the run "was not run
using default settings": its details list **Z-Buffering 16 bit**, the
only depth the driver offers (the G96 keeps it as Z24S8 internally).

## The driver afterwards

V9XTRACE snapshot (`V9XSNA2.INI`), counters since boot 13 (they include
the earlier V9XD32 runs on the same boot):

- `FlipHandled=5837`, `FlipDeclined=0`, `FlipForcedIdle=0`,
  `BltFlipWaited=5764`: 3DMark's frames were presented by engine flips.
- `EngineFifoTimeouts=0`, `EngineIdleTimeouts=0`, `EngineResets=1` (the
  bring-up). No new NV50 fault record: `V9XN50F.TXT` and `V9XTRACE.INI`
  are boot 12's (HAL `3ba059d5`, the Z16 fault).
- Texture pool: 33,423,360 bytes, peak 19,998,208, none refused;
  `TexturePlaced=1139`.
- `M64Policy19=160`, the guard-band drops the GeForce 210 also shows.
  `M64Policy08=4`, `M64Policy11=8`, `BatchesEngineRefused=12` and
  `M64TexOpRefused=00000108`: refusals on this boot that the cumulative
  counters cannot attribute to 3DMark or to V9XD32.
