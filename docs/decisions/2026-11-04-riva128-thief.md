# RIVA 128ZX: Thief in Direct3D, fullscreen, nothing refused

Date: 2026-11-04

Machine: M-7V636C (remote help), RIVA 128ZX 8 MiB, Windows 98 first
edition, boot 36, driver f03d3513 (V9XHAL.DLL and V9XDISP.DRV hashes match
the build). Plan: `docs/plans/nvidia-riva128-d3d.md`, step 6. Files:
`docs/probe/m7v636c-riva128-games-2026-11-04/thief-*`.

## Setup

The owner's Thief: The Dark Project 1.33 (`C:\Games\Thief`) was already
set to Direct3D (`game_hardware 1`, `d3d_driver_index 0`), fullscreen at
640x480x16. `Thief.exe` imports `ddraw.dll` itself; the ddfix wrapper in
the folder is not in its path. Nothing in its configuration was changed:
the five `.cfg`/`.ini` files hash-match copies taken before the run, and
the run loaded the owner's "Lord Bafford's Manor" save without saving.

Boot 36 came up with the network password dialog still open behind the
desktop and no Explorer, so the agent refused screenshots ("desktop not
ready"). Clicking the dialog and pressing Escape fixed it.

The game is fullscreen with page flips, which the agent's screenshot does
not see. The frames here come from the driver's flip-path grab
(`V9XTRACE -grab:<interval>x<count>`), which writes the presented buffer.
The menu is 2D and the agent's screenshot shows it (`thief-menu.png`).

## Result

Over about three minutes in the mission (`thief-end-SNAP.INI`; the boot's
counters were zero before the load, `thief-base-SNAP.INI`):

- 719,438 draws, 6,199,183 triangles, 688,612 textured, 186,921 blended.
- **0 refused**, no engine idle timeouts, 8,759 flips.
- 53 texture creates.

The grabs (`thief-grab-start.png`, `thief-grab-torch.png`,
`thief-grab-6.png`, the view turned by mouse) show the lit stonework, the
banner, the floor, a torch flame blended over its niche and the HUD, with
no missing or wrong polygons visible at that size.

## Not done

- No comparison against another renderer: correctness is by eye.
- Only the start of one mission, standing and turning; no walking, no
  water, no in-game menu over the 3D view.
- The folder's `cam.cfg` carries a commented-out `safe_texture_manager`
  line, with a note that Thief 2 may not work properly on the RIVA 128
  without it. It was not needed here; Thief 2 (`C:\Games\Thief2`) was not
  run.
