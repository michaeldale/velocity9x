# Carrizo R7E on 0.54.0: the MODULATE alpha check passes, 3DMark 2001 SE runs clean

Date: 2026-11-17. Machine: M-XP7053 (myne's HP with the AMD GX-420GI,
Radeon R7E `1002:9874`, Carrizo, GCN 3), over the relay; boot 71 before,
boot 72 after. Evidence:
[`../probe/carrizo-0.54.0-m-xp7053-2026-11-17/`](../probe/carrizo-0.54.0-m-xp7053-2026-11-17/).

The Carrizo shares `vi_cp.c` and `d3d_vi_map.c` / `vi_shader.c` with the
Oland, so two of 0.54.0's changes reach it untested:
- the ring's read pointer read from the writeback copy
  ([issue](../issues/2026-11-17-oland-3dmark2001se-cp-stall-hang.md));
- DX5 MODULATE keeping the texel's alpha
  ([record](2026-11-17-oland-dx5-modulate-keeps-texel-alpha.md)).

The machine was offline for the 0.54.0 release checks. Its owner switched
it on afterwards.

## What ran

1. **Before (boot 71):** V9XD32 with the T20 ModAlpha check (bdcc2bbe's
   probe), default and `/bpp16`, on the driver it had (`V9XHAL.DLL`
   SHA-256 `58E27B37...C773`, from before 0.54.0).
2. **Install:** the released `velocity9x-0.54.0-ati.zip`'s DRV, VXD,
   HAL, SETP and GL. Boot 71's five files were backed up first (session
   scratchpad). The new files went in by WININIT rename and `reset`, and
   all five matched the zip's after the restart.
3. **After (boot 72):** the same V9XD32 at both depths, then 3DMark
   2001 SE's default benchmark with V9XTRACE snapshots either side, using
   the release's V9XTRACE.

## Results

| | Before (boot 71) | After, 0.54.0 (boot 72) |
|---|---|---|
| `T20ModAlphaOk`, 32 bpp | 0: grey, grey, grey | 1: 808080h, FF0000h, 00FF00h |
| `T20ModAlphaOk`, 16 bpp | 0: 8410h at all three | 1: 8410h, F800h, 07E0h |
| Every other V9XD32 verdict, Ok and Result key | PASS, both depths | identical, PASS |

3DMark 2001 SE, default benchmark at 1024x768x32, 32-bit textures:
- the score window appeared after 6.1 minutes, showing 724 (recorded, not
  compared), with 7 of 7, 6 of 6 and 4 of 4 tests;
- `EngineIdleTimeouts` 0 before and after;
- no `M64Policy*` counter changed: nothing was refused;
- `DrawsIntoPresented` unchanged;
- 3,260 flips and about 90,600 RenderPrimitive calls during the run.

So on GCN 3:
- the MODULATE change does what it did on the Oland, with nothing else
  in V9XD32 moved;
- the writeback read pointer drives a whole 3DMark 2001 SE run without
  a stall.

One run is not proof against an intermittent stall, but before the fix
the Oland stalled within one or two runs.
