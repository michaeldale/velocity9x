## How the run went

One run of all seven (`run-release-checks.ps1 -ThreeDMark`), then the
GM965 again. Its first worker installed 8 of 8 (boot 53 to 54) but
stopped in 3DMark at Windows' "Enter Network Password" dialog, which the
machine shows after a reset; no probe ran. The dialog was closed by hand
(`close-window`), and the GM965 rerun installed again (boot 54 to 55).
A watcher looked for the dialog six times after that reset and found
none; 3DMark started 45 s after the install and every probe passed. Why
the dialog came after one reset and not the next was not checked. Both records were moved aside and this one written by
`-SummaryOnly` over the seven folders. A switch to rerun one machine
without installing again is proposed in
[release-checks-skip-install.md](../plans/release-checks-skip-install.md).
