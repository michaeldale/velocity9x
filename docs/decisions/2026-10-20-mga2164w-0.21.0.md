Date: 2026-10-20. Machine: A8U4I5, Matrox Millennium II (MGA-2164W,
102B:051B, 8 MiB), boot 513. The matrox package was built from
`31db509b` (0.21.0 code, a clean tree) and installed by WININIT rename
over the boot-509 `d1a6f262-dirty` set. Renamed: DRV, VXD, HAL, SETP,
GL, trace, GLIDE2X, GLIDE3X. `ATI3DCIF.DLL` in SYSTEM is ATI's own
(179,200 bytes) and was left. The previous files are kept off-tree.
Evidence: [`../probe/a8u4i5-mga2164w-0.21.0-2026-10-20/`](../probe/a8u4i5-mga2164w-0.21.0-2026-10-20/).

`EngineCaps=00010017`, as on boot 509.

## 3DMark 2000 (build 340), default benchmark

1024x768x16, triple buffered, Z16, 16-bit textures: **262 3DMarks**,
CPU 36. Recorded, not compared: no earlier 3DMark 2000 run on this card
exists.

| Test | Result |
|---|---|
| Helicopter low / medium / high | 4.7 / 3.2 / 1.2 fps |
| Adventure low / medium / high | 5.0 / 4.1 / 3.6 fps |
| Fill rate single / multi | 14.0 / 47.3 MTexels/s |
| High polygon 1 / 4 / 8 lights | 140 / 129 / 138 KTriangles/s |
| Texture rendering 8 / 16 / 32 / 64 MB | 10.4 / 6.3 / 4.6 / 2.8 fps |
| Bump mapping, all four | not supported |

The single-texturing fill rate is below multi-texturing. That was not
investigated.

Twelve frames were filmed; frames 2, 3, 4 and 8 are kept
(`3dmark2000-film/`). The game scenes draw
textured. Explosion particles (frame 2), a sail (frame 3) and the
sprites in frame 8 draw as untextured white quads. That fits the
card's recorded limits (no blending; 4444, fog and specular refused;
STATUS.md) and `MgaTexRefusedFormat=218` below. It is not new, but
nothing earlier shows this benchmark, so that is inferred, not
compared.

## The engine

One snapshot, after the benchmark (`V9XSNA7.INI`, boot id
`2026-10-20 14:18:25.39`, `BuildsAgree=1` on 31db509b). It covers
V9XD32, V9XDDP, V9XR3DP, V9XGLP and 3DMark 2000.
- 0 FIFO or idle timeouts, 0 resets, 0 flips declined.
- 7,825 batches refused by the engine. `MgaSetupRefusedSplit` 37,591
  and `MgaSetupRefusedBuild` 1: the setup refusals 0.20.0's changelog
  lists as a known limit.
- Textures refused: 218 for format, 125 for placement, 1 for surface.
  The last refused was 128x128, 16 bits, pitch 256.
- `Dp2Records=0`. Nothing this boot drew through DrawPrimitives2, so
  0.21.0's DP2 texture-coordinate change was not exercised on this
  card.
