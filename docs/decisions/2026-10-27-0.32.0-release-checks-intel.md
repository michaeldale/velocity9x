# 0.32.0 release checks: the HD 4600 and the GMA 950 netbook

Date: 2026-10-27

Status: measured on two machines, both on `100e041c` (main at the 0.32.0
bump) from a clean tree (`build=100e041c` in V9XHAL.DLL). Not covered:
the Rage 128 (A8U4I5) and the HD 5450. The HD 5450's page-flip fix
(`0fe58857`) lands after this build, so the release build will be a new
commit and the ati package needs its own run on it.

Evidence: [`../probe/0.32.0-release-checks-2026-10-27/`](../probe/0.32.0-release-checks-2026-10-27/).

## Builds

The intel-gma package's DRV, mini-VDD, HAL, SETP, GL, GLIDE2X, GLIDE3X
and ATI3DCIF went in by WININIT rename, and each machine restarted by
`reset`. After the restart, the staged files were gone and every
installed file's SHA-256 matched the package: the 4570 on boot 104, the
netbook on the boot after (its `reset` reply timed out at 120 s, so the
renames are the evidence it restarted). Probes ran from `C:\V9XREL`, with
no DLLs beside them.

## Notes

- 3DMark 2000's default settings are refused on the netbook (they need
  1024x768). It then offers 1024x576, 16-bit, which is what ran.
- Half-Life rewrites `qconsole.log` at each launch, even with
  `-condebug`. The check script first threw the run's lines away;
  the figures above are from the logs kept in the evidence folder.
- Nothing ran through COMMAND.COM. Programs were started directly,
  Half-Life's engine was chosen by `regedit /s`, and the netbook's
  Half-Life was closed by the agent's `kill`, since it has no WCLOSE.
