# 0.30.1 release check: the package on the GMA 950 netbook

Date: 2026-10-26

Status: measured on one machine. 0.30.1 is 0.30.0 plus the GMA 3100
binding ([`2026-10-26-g33-gma3100-from-a-survey.md`](2026-10-26-g33-gma3100-from-a-survey.md)),
so the check is that the GMA 950 path is unchanged.

## What ran

The intel-gma package from a clean `66ab7fcb` (`build\win98se-intel-gma`),
on the netbook at boot 256, the boot after 0.30.0's checks (`cdbf4cb6`,
boot 255). V9XDISP.DRV, V9XMINI.VXD, V9XHAL.DLL, V9XSETP.DLL, V9XGL.DLL,
GLIDE2X.DLL, GLIDE3X.DLL and V9XTRACE.EXE by WININIT rename, restart by
`reset`. The DRV, mini-VDD and HAL read back byte-identical to the
package (SHA-256); the rest match in size.

| Check | Result |
|---|---|
| V9XBOOT.INI | `Stage=enable-ok`, `DriverInitResult=ok` |
| Write-combining | `MtrrWrite=ok s=2 b=d0000001 m=ff000800`, as 0.30.0 |
| V9XHW.INI | `Adapter=Intel GMA 950 (945GSE)`, `DeviceId=27AE` |
| V9XD32 /ddi6 | PASS, `Failures=0x00000000` |
| V9XD32 /ddi5 | PASS, `Failures=0x00000000` |

## Not run

- The INF: the files were renamed in, not installed by Have Disk, so the
  new `DEV_29C2` line was exercised only by the build's own checks.
- Any G31 or G33.
- The OpenGL and Glide probes, Half-Life and 3DMark on this build. The
  code they run is 0.30.0's, checked on 2026-10-26.
