# Desktop HD 4000 on 0.56.0: every probe passes, 3DMark 2000 3121, 2001 SE 1743

Date: 2026-11-19. Machine: M-NZHWBR (W9QI54F0), Daniel's i5-3570K on an
MSI 7-series board, remote help. The owner took the Radeon HD 2400 Pro out
on 2026-11-18, leaving the CPU's HD 4000 (8086:0162). Before this run it
was already on an older intel-gma build at 1024x768x32 (boot 52;
`Palette=route=0`, `PatWrite=ok`).

Status: measured, one run each. Build: the 0.56.0 intel-gma package
(`b0a945a5`), installed by `scripts/run-release-checks.ps1 -Machine hd4000`
(new list entry; the `hd2600` entry is switched off so the ati package is
never sent here). Boot 53, eight of eight files' SHA-256 matching the
package, V9XTRACE `HalBuild=0.56.0 b0a945a5`, `BuildsAgree=1`.

Evidence: [`../probe/hd4000-nzhwbr-ivb-2026-11-19/`](../probe/hd4000-nzhwbr-ivb-2026-11-19/),
including the runner's own record of the run.

## Why it was run

No desktop Ivy Bridge had run the driver since W9QI4E14 went offline on
2026-10-28. Shared with the HD 4600 and never run on a desktop HD 4000:
write-combining through PAT, batches without the first render-target
flush, one texture stage per pass (`efef10e0`, measured only on the
mobile 0166), and 0.56.0's slot-long batches and indexed pieces.
