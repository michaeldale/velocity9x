# GeForce 9500 GT (G96): OpenGL runs on the GeForce 210's path, Quake 3 demo at 44.1 fps

Date: 2026-11-28

Machine: M-Z2T02D (GitHub issue 30), remote help, boot 13: the `nvidia`
set from 3a1335ec (HAL with the G96's Direct3D, the "Velocity9x GeForce
9500 GT" name), ICD `V9XGL.DLL` build 3ba059d5-dirty, desktop
1024x768x32.

Evidence: [`../probe/g96-opengl-m-z2t02d-2026-11-28/`](../probe/g96-opengl-m-z2t02d-2026-11-28/).

## No code change

The ICD reaches the card through the render interface, which
`v9x_r3d_describe` (d3d_core.c) answers per engine. The 9500 GT runs the
GeForce 210's NV50 engine, so it gets that engine's description
(video-memory textures 1 to 2048, all three interface formats; see
[2026-11-16-gt218-opengl-describe.md](2026-11-16-gt218-opengl-describe.md)),
with the renderer named by PCI device since 3a1335ec. Nothing was
changed for this run.

## V9XGLP

`Result=PASS`, `Renderer=Velocity9x GeForce 9500 GT` (probe binary
6244dc08-dirty, unchanged since 2026-11-26). Against the GeForce 210's
last run (W9QI0DAD, 2026-11-25, `gt218-mipmaps-w9qi0dad-2026-11-25`,
16 bpp) every pixel read-back is the same, mipmap levels included
(`MipQuad16` 000000FF, `NonSqMipL2` 0039C300, `SgisMip*Off4` L4), except
one:

| | GeForce 210 | 9500 GT |
|---|---|---|
| `DepthFineRead` | 0000FF00 | 00FF0000 |
| `DepthFineResolved` | 0 | 1 |

The fine-depth check asks for two surfaces closer than 16-bit Z can
separate. The 9500 GT's depth buffer is Z24S8 (NV84_3D has no Z16,
[2026-11-28-g96-direct3d.md](2026-11-28-g96-direct3d.md)), so it
resolves them. `LitResult=differ` as on every GeForce 210 run (310 of
359 V9XGLP reports in `docs/probe` read `differ`).

ICD counters for the probe: 1,174 textured batches on the card, 0 on
the CPU, 0 refused, 123 texture creates, none failed.

## Quake 3 demo

The 1999 demo (`quake3.exe` 11-29-99, `demoq3\pak0.pk3`) was copied
from `build\q3demo-haswell` to `C:\Q3Ademo` over the relay (47 MB, CRC
checked). The tester's activity log was told first. Command as on the
Oland: `quake3.exe +set logfile 2 +set s_initsound 0 +set r_fullscreen 0
+set r_mode 3 +set nextdemo quit +timedemo 1 +demo demo001`.

Quake 3 reported `GL_RENDERER: Velocity9x GeForce 9500 GT`, GL 1.1.0,
32-bit colour with 16-bit Z (the pixel format it asked for; the HAL
stores Z24S8), `GL_ARB_multitexture` not found, 640x480 windowed.

| Run | Result | ICD |
|---|---|---|
| 1 | 1346 frames, 30.5 s: **44.1 fps** | hw 212,268 batches / 5,329,216 triangles; cpu 0; refused 0; 355 textures (6,286 KB), none failed, no evictions |
| 2, four agent screenshots during it | 1346 frames, 31.9 s: 42.3 fps | not read |

Run 2's first screenshot (`q3-run2-frame.png`) shows the level lit and
textured, a player model, a rocket explosion, blood decals, the weapon,
the HUD and the face, all drawn correctly. The other three were taken
after the demo had ended and show the desktop.

The scores are recorded, not compared: the Oland's 72.9 fps was at
16 bpp on another CPU.
