# SiS 6326 on the 0.61.0 tree: probes pass but V9XD32's X8R8G8B8 texture, and its first 3DMark 2000 run completes at 640x480

Date: 2026-11-27. Machine: A8U4I5 (Pentium III 1 GHz, 128 MiB, Windows
98 SE), its SiS 6326 rev 0B (`1039:6326`, subsystem `1569:6326`, 4 MiB;
card 2, the one that does not lock the machine). Build: the `sis`
package of `6244dc08-dirty` (the 0.61.0 tree), installed by
`run-release-checks.ps1 -Machine sis6326` (WININIT renames, `reset`,
8 of 8 files hash-checked, boots 724 to 726). The fifth card of the
A8U4I5 round and the first `sis` boot of the 1.0 work; the last
Velocity9x runs on this card were October's.

## Getting the card onto our driver

The devnode still pointed at Velocity9x's SiS key (`Display\0010`) and
the stored mode was 800x600x16, but Windows came up in 16-colour VGA
with "There is a problem with your display settings": `SYSTEM` held
the Voodoo4's `3dfx` files from the previous card. The runner's
install of the `sis` set fixed it; nothing else was changed.

## 3DMark 2000

The runner's 3DMark step stopped at 3DMark's "can not use the default
display settings" box (1024x768 needs 16 MiB), as on the other cards
of 4 MiB or less. Run by hand instead: a new project, Display and CPU
Settings to 640x480x16 (16-bit Z, triple buffer, 16-bit textures;
3DMark reported 2400 KB of video memory used), the default tests,
the agent's VNC server stopped first (it went with the Rage IIC's
locks).

- Ran to its score, **210** (recorded, not compared), in about 10
  minutes. The first 3DMark 2000 run on the card; October ran 3DMark
  99.
- Across the run: 1,633 flips accepted, 121,104 primitive calls, none
  drawn into the presented buffer, no engine reset
  (`sis6326-3dmark-640/snapshot-before.ini`, `snapshot-after.ini`).
  `FlipStillDrawing` counted 3,938,793 retries, DirectDraw polling
  while a flip waited for the retrace.
- 24 live screenshots, every 30 seconds, show both game tests and the
  feature tests drawn correctly (`3dmark2000-live-screenshots.jpg`;
  one black frame is between tests).
