The aperture is 256 MiB. That bounds what the CPU can see, not the
board's VRAM: `CONFIG_MEMSIZE` (phase 2, register read) is still the
measurement. The BIOS's VBE figure stays 16 MiB (`mem=256` x 64 KiB).
Which BAR number holds the 64 KiB register window, and whether any BAR
is 64-bit, is not visible here; the plan's open question about
`rs690_hw16.c`'s BAR read stays open.
