## What changed since 0.44.0

Every probe verdict compared with `0.44.0-release-checks-2026-11-08`, by machine and check.

- **i5-4570, HD 4600**:
  - V9XD32 default: T19PushVerdict pass to (absent), T19FourTexVerdict pass to (absent), T19KillVerdict pass to (absent), T19BemVerdict pass to (absent), T19PushFogVerdict pass to (absent), T19KillFogVerdict pass to (absent), T19CubeVerdict pass to (absent), T19NormalVerdict pass to (absent), T19Dxt1Verdict pass to (absent), T19Dxt3Verdict pass to (absent), T19 PASS to SKIP-NO-PS
  - Not caused by 0.45.0: test residue. SYSTEM.INI held
    `[Velocity9x.Direct3DDdi] V9XD32.EXE=6` before the run (every switch
    run reports `DdiPrevious=6`; 0.44.0's reported `(none)`), so the
    default run got DDI 6, whose caps have no pixel shader (`MaxStreams`
    0, PS `FFFF0000`). It was left that afternoon, when a `/ddi6` V9XD32
    was killed mid-run for the dead-program tests and never restored its
    override; the probe keys it on the name V9XD32.EXE whatever its file is
    called, and puts back the previous value, so it stayed. The line was
    removed from SYSTEM.INI (get, edit, put) on the 4570 and the netbook,
    which had it too, and the default run repeated on the same boot (200):
    `MaxStreams=1`, PS `FFFF0101`, T19 PASS, `Failures=0`
    ([`hd4600/v9xd32-default-rerun-no-override-V9XD32.TXT`](../probe/0.45.0-release-checks-2026-11-10/hd4600/v9xd32-default-rerun-no-override-V9XD32.TXT)).
    The netbook's GMA 950 has no DDI 8, so no verdict there changed.
