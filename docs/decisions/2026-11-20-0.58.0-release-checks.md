## Notes (by hand)

- Two runs make this record: the LAN machines (gma950, oland) first; the
  three remote-help machines failed at once in that run ("Not
  reachable": the scratch controller copy that relays this release's
  HAL with PipelineWindow 4 needed `V9XSIGN` set) and were rerun with it
  and `-SkipProbeBuild`, into the same folder. This record is
  `-SummaryOnly` over both.
- The HD 3000 has no entry in the personal machine list yet; it ran from
  a scratch copy with one added (`D32Runs` default, `/bpp16`, `/ddi6`,
  `/ddi5`).
- V9XSNA "NOT-RUN (no report)" in every column is the runner's card read
  before install, new since 0.57.0's checks; each card matched its
  `PciId` (Builds table).
- Oland V9XD32 T19 FAIL: the same rows as 0.57.0 (no verdict changed),
  the known specular-with-fog mismatch.
- Carrizo's windowed DirectDraw present read 2.10 ms against 0.90 ms in
  0.57.0; OpenGL unchanged. Not a verdict and not traced. This release's
  GCN change is to unsynced flips, which a windowed present does not use.
- Offline or not ready on the day: hd4600, gm45, jjn1zz, rs690 (no
  answer), riva128 (desktop not ready); trinity's entry has an HD 7470
  fitted.
