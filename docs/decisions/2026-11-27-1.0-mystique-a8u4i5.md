# Mystique on the 0.61.0 tree: probes pass but V9XD32's 32-bit textures and the known Glide blend, and its first 3DMark 2000 run leaves Adventure partly black

Date: 2026-11-27. Machine: A8U4I5 (Pentium III 1 GHz, 128 MiB, Windows
98 SE), its Matrox Mystique (MGA-1064SG, `102B:051A`, subsystem
`102B:051A`, revision 02, 4 MiB) in PCI slot 8. Build: the `matrox`
package of `620b48c3-dirty` (the 0.61.0 tree), installed by
`run-release-checks.ps1 -Machine mystique` (WININIT renames, `reset`,
8 of 8 files hash-checked, boot 731 to 732). The eighth card of the
A8U4I5 round; the last runs on this card were October's
([record](2026-10-19-mystique-direct3d.md)).

## Getting the card onto our driver

The devnode points at `DISPLAY\0016`, the Velocity9x Millennium II key;
the `matrox` package's one set of files serves both chips, so 3DMark
and Display Properties name the card "Millennium II MGA-2164W"
(cosmetic). Windows came up in 16-colour VGA on the ViRGE/DX's `s3`
files and installed the monitor from `MONITOR.INF`; the runner's
install of the `matrox` set fixed the rest.

## Release checks

| Check | Result |
|---|---|
| V9XD32 `/bpp16` | FAIL, two checks: T22A and T22X, 32-bit textures drawn black |
| V9XGLIDP | FAIL at `BlendHalf` (`FFFF` where `8410` is expected) |
| V9XGLP, V9XWPRS, V9XFBCMP | PASS |
| V9XR3DP | COMPLETE |

T22 is the first run of that test on the card: both textures are
created, locked and drawn without an error and every judged pixel
reads 0, as on the Voodoo4. Not filed separately: it is the same
symptom as the Voodoo4's and the other older engines', left for a later
release on those. **BlendHalf** is not new: the Mystique read the same
`FFFF` in October (`a8u4i5-mystique-gl-glide-2026-10-19`), as does the
Millennium II; the engine has no blender.

## 3DMark 2000

The 16 MiB default refuses 4 MiB, so it ran by hand at 640x480x16,
16-bit Z, triple buffered, default tests, VNC stopped: **411**
(recorded, not compared), the first 3DMark 2000 run on the card. 2,651
flips, 95,999 primitive calls, 10,132 batches refused by the engine
(`MgaSetupRefusedSplit=45120`, `MgaTexRefusedPlace=911`), nothing into
the presented buffer, no timeout or reset.

Live screenshots every 30 seconds
(`mystique-3dmark-640/3dmark2000-live-screenshots.jpg`): Helicopter's
smoke and explosions are white boxes, the Matrox limit the Millennium
II showed in October ([record](2026-10-20-mga2164w-0.21.0.md)); in
Adventure large areas of ground and sky are black in several frames,
which the Millennium II (8 MiB) did not show
([issue](../issues/2026-11-27-mystique-3dmark2000-adventure-areas-missing.md)).
The 911 refused texture placements suggest 4 MiB running out; not
confirmed.
