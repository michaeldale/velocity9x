# 0.33.0 release checks: the HD 4600, the GMA 950, the HD 5450 and the Carrizo

Date: 2026-10-29

Status: measured on four machines, all on `316eca18` (main with the
0.33.0 changelog) from a clean tree (`build=316eca18` in V9XHAL.DLL of
both packages). Not covered: the Rage 128 (A8U4I5), whose agent did not
answer, and the Ironlake (M-J0F0SJ), offline since 2026-10-28.

Evidence: [`../probe/0.33.0-release-checks-2026-10-29/`](../probe/0.33.0-release-checks-2026-10-29/)
(`hd4600`, `netbook`, `hd5450`, `carrizo`). The installed files saved
before each deploy and the two Quake 3 `V9XGL.LOG`s (9.5 MB on the
HD 5450) are left out.

## Builds

The intel-gma package went to the 4570 (HD 4600) and the netbook
(GMA 950), and the ati package to M-BXMFA8 (HD 5450) and M-XP7053
(Carrizo R7E). All eight files went in by WININIT rename, and each
machine restarted by `reset`:
- the 4570 on boot 110;
- the netbook on boot 258;
- the HD 5450 on boot 45;
- the Carrizo on boot 41.

After each restart, the staged files were gone and every installed file's
SHA-256 matched the package. The probes ran from `C:\V9XREL`.

The probes were rebuilt from this tree before the run that counts. Their
reports read `316eca18-dirty` because this evidence folder was untracked
at the time; the driver files are the clean build.

## Notes

- **The first probe run was invalid, and was redone.**
  - Git Bash rewrote V9XD32's `/ddi7` into a Windows path, and `-File`
    passed the switch list as one argument, so V9XD32 never wrote a
    result.
  - V9XR3DP in `build\r3d-probe` was a 23 October build (`002b6a4b-dirty`).
    Against this HAL's render interface its negotiation failed
    (`NegotiateWrongVersion=1`, `Result=FAIL-NEGOTIATE`).
  - All four probes were rebuilt and run again from a script that holds
    the switches, and every result above comes from that run. The R3DP
    probe is not rebuilt by `run-checks.ps1`.
- **3DMark 2000's device name.**
  - On the HD 5450 it now names the driver "Velocity9x AMD Radeon HD 5450
    (Cedar)". At boot 39 it read "Velocity9x VBE-generic display".
  - The Carrizo still reads "VBE-generic display".
  - Neither is looked into.
- The netbook's 3DMark 2000 refuses its default settings (they need
  1024x768) and offers 1024x576 at 16 bits, as at 0.32.0.
- The HD 5450 trees issue was not looked at in these runs; see the
  changelog's known issue.
