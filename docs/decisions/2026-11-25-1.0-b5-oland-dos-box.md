# B5 on the Oland R7 250: the full-screen DOS box round trip returns to a repainted desktop, and the probes after it read as before

Date: 2026-11-25. Machine: W9QI0DAD (AMD FX-6300, Windows 98 SE),
Radeon Oland XT `1002:6610` on the `ati` package, the B8-fix set
(`V9XHAL.DLL` SHA-256 `7BAFCE3A...`, build label `a92e01f3-dirty`,
`V9XDISP.DRV` `DDCA9390...`), boot 133, 1024x768x32, remote agent
0.19.0. The first `ati` Radeon to run B5.

## What was run

The 86Box round trip of
[2026-11-24-1.0-b5-b9-86box.md](2026-11-24-1.0-b5-b9-86box.md),
driven by the agent (`dos-roundtrip-phys.ps1` in the evidence): Start >
Run `command`, `echo AAA` windowed, Alt+Enter, `echo BBB` in full screen
(ended by CTRL+M), Alt+Enter back, `echo CCC`, `exit`. The agent was
asked for `info` after every step and took a GDI screenshot wherever GDI
owns the screen (before, windowed, after the return, after `exit`).

## Result

- The agent answered at every step, including both full-screen steps.
- After the return the DOS window shows AAA, BBB and CCC in order, with
  the desktop repainted around it (`6-echo-ccc.png`). `BBB` there is the
  command typed while full screen, so the session ran across both
  switches.
- `exit` leaves a clean desktop (`7-exit.png`).
- After the trip, without a restart: V9XWPRS `Result=PASS` (DirectDraw
  read-back, GDI over it, and OpenGL "Velocity9x Radeon Oland" all
  pass); V9XD32 (`C:\V9XREL`) `Failures=0x00000001`, T19 only. Every
  `T*Result` line is identical to the B8-fix release check on this
  machine
  ([`../probe/1.0-b8-fix-oland-2026-11-23/release/oland/`](../probe/1.0-b8-fix-oland-2026-11-23/release/oland/)).
  T19's failure predates this run.
- `V9XBOOT.INI` is byte-identical before and after.

## What this does not show

Nothing captured the full-screen screen. OBS, which watches this box's
HDMI, was not connected, and the agent's GDI screenshot cannot see a
full-screen DOS VM. That the machine entered full screen rests on the
key sent and on the session behaving as it did on 86Box, where the
capture showed it. Nobody looked at the monitor during the run.

## Left for B5

passed on 86Box (Millennium) on 2026-11-24.
