# RIVA 128ZX and HD 3000 on the 0.61.0 tree: both as on 21 November, and the HD 3000's 3DMark 2000 draws correctly

Date: 2026-11-27. Two remote-help machines, over the relay, both
reached by `run-release-checks.ps1 -Machine riva128,hd3000` with the
0.61.0 tree's packages (`620b48c3-dirty`; WININIT renames, `reset`,
8 of 8 files hash-checked each). Both last ran release checks on the
21 November baseline
([record](2026-11-21-1.0-baseline-checks.md)), before the B1, B3 and
B8 fixes.

- **M-7V636C**, RIVA 128ZX (`12D2:0018`), `nvidia`, 800x600x16, boot
  74 to 75 (the logon box was dismissed by the runner).
- **M-NZHWBR**, i3-2105 HD 3000 (`8086:0112`), `intel-gma`, 1024x768x32,
  boot 72 to 73, then 73 to 74 for the 3DMark run.

## HD 3000: 3DMark 2000

Default benchmark, 1024x768x16, run by the runner (an entry for it was
added to the private machine list): **8519** in 5.4 minutes, 35,164
flips, 2,363,781 draws, none refused, none into the presented buffer,
no engine stall. The machine has `VSync=2` (vsync forced off; 40,432
flips overridden), so the score is diagnostic only and not comparable
with 20 November's 4015, which was not taken that way.

The ten grabs (`hd3000-3dmark/hd3000/3dmark2000-grabs.jpg`) at first
looked wrong: the ground is a dark blue lake with reflected trees in
most frames. Their HUD clocks read 0.2 to 3.8 s: with frames about
twice as fast, the grabs fell in the opening seconds over the lake,
which the first of 20 November's grabs also shows. A second run with
live screenshots through the relay
(`3dmark2000-live-screenshots.png`) shows textured terrain and forest
(the dense tree rows match the owner's own 20 November screenshot),
smoke, Adventure's town at 153 fps and the feature tests. One frame has
the cockpit panels drawn smaller and nearer the centre; not explained
from one frame.
