VELOCITY9X - INSTALLING THE DRIVER

@FAMILY_SUMMARY@

Velocity9x is a display driver for Windows 98 SE. It replaces the driver
Windows uses for your display adapter and adds DirectDraw, Direct3D and
OpenGL acceleration.

BEFORE YOU START

1. Close every program.
2. Make sure you can get back to a working desktop if the new driver does
   not start: know how to reach Safe Mode (F8 before Windows starts), and
   keep a backup of anything you cannot lose. RECOVER.TXT, in this folder,
   has the steps for going back.
3. Copy this whole folder to the machine's hard disk, for example C:\V9X.
   Windows reads the driver files from it during the install.

INSTALL

1. Open Control Panel, System, Device Manager.
2. Expand Display adapters and open the fitted display adapter.
   Intel graphics appear twice. If Display adapters lists "Standard PCI
   Graphics Adapter" and "Standard PCI Graphics Adapter (VGA)", open the
   one ending "(VGA)". Do not install on the other, or on an "(Unknown
   Device)": the driver cannot start there and Windows stays at 16
   colours.
3. Select Driver, then Update Driver.
4. Choose "Display a list of all the drivers in a specific location".
5. Choose Have Disk and browse to this folder.

AFTER THE RESTART

@MODES_AFTER_FIRST_BOOT@

Display Properties gains two tabs, Velocity9x and Velocity9x Advanced.
The first shows the card, video memory, mode and which acceleration is in
use, and has "Check for updates..." and "Copy report". The second holds
the driver's settings. If they appear under Settings, Advanced instead,
they move back to the top after the next restart.

@GLIDE@

V9XGL.DLL is the OpenGL 1.1 driver. OpenGL programs use it on a desktop
the card can draw into, and Windows' own software OpenGL everywhere else.

IF SOMETHING GOES WRONG

If Windows does not reach a desktop, do not keep restarting. Follow
RECOVER.TXT. If the desktop appears but something draws wrongly, use
"Send report..." on the Velocity9x Advanced tab, or "Copy report" on the
Velocity9x tab, and describe what you saw.

The driver writes what it found at each boot to C:\V9XDIAG. Those files
are what a report contains; a report is sent only when you choose
"Send report...".

FOR TESTERS

The folder also carries test programs. None is needed to use the driver.

  V9XSET.EXE     status panel, safe to run before installing
  V9XSTAGE.EXE   preflight: loads the driver without installing it or
                 changing the mode
  V9XGDI.EXE     drawing and pixel readback test, after the desktop is up
  V9XMSW.EXE     mode switching: /set:WxHxB, /cycle:N, /depth:N
  V9XFIX.BAT     stages driver files through WININIT.INI when an
                 installed build is too unstable to update normally

At boot the driver writes progress lines to COM1, ending with
"V9X-DRV enable-ok mode=@DEFAULT_MODE@" on a good first boot.
